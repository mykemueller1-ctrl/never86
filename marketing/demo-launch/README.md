# Never86’d sample demo launch kit

Prepared September 9, 2026. This is a reviewable launch package. Nothing has been posted, sent, scheduled, or purchased.

The first release to promote is a public demo with synthetic records and deterministic checks. It is separate from a live restaurant account. Live AI, photo extraction, account sync, and a ChatGPT store listing are not complete.

## Files to use

| File | Purpose |
| --- | --- |
| `linkedin-founder-post.txt` | Main founder post, ready to paste after the demo link and feature claims pass review |
| `x-thread.json` | Five short posts, with separate text fields and a video attached to the first post |
| `landing-copy.json` | Exact headline, buttons, cards, offer language, disclosure, and image text |
| `demo-video.md` | A 60 second recording script, edit directions, captions, and asset checklist |
| `seven-day-rollout.md` | A measured launch with followup copy and a production workflow for agents |
| `ten-minute-scorecard.csv` | A blank observation sheet for real operator tests |
| `claims-and-release-checks.md` | Claims that can be made, what needs proof, and a copy audit |
| `publishing-sources.md` | Current official LinkedIn and X guidance with source links |

`DEMO_URL` is a deliberate placeholder. Replace it with the verified public sample demo URL. Do not substitute the private Community review URL or a production restaurant portal. The final video must record the deployed sample demo and show the sample label throughout.

Recommended launch: one founder video, one focused thread, then individual followups about the problem operators choose. The target is a completed, understood check within ten minutes. Views and likes are distribution signals, not evidence that the product works.

One location plus one seat free is the planned product offer. Additional manager seats will be paid. This package does not announce that live seat provisioning or billing is available.
